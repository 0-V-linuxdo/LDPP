# LD++

LINUX DO（linux.do）增强用户脚本。它把两个旧脚本合到一个脚本里重新实现：

- 「LINUX DO 话题屏蔽」（LINUX-DO-Topic-Blocker）
- 「话题 & 回复 总结」（linux-do-summary-userscript，含 DeArrow）

这是净室重写，没有复制旧代码。架构参照 [Void++](https://github.com/0-V-linuxdo/VoidPP/tree/dev)：插件化、Proxy 设置仓库、Bun 构建。

## 安装

1. 先在 Tampermonkey / Violentmonkey 里**停用**旧的屏蔽脚本和总结脚本。同时开着会重复处理话题列表，旧问题会回来。
2. 安装 [`userscript/LDPP.user.js`](https://raw.githubusercontent.com/0-V-linuxdo/LDPP/main/userscript/LDPP.user.js)（打开这个链接，脚本管理器会弹出安装页）。之后脚本管理器会自动从本仓库检查并安装新版本。
3. 打开 linux.do，点顶栏的齿轮图标（或脚本菜单「⚙️ LD++ 设置」），在「AI 接口」页填入 OpenAI 兼容的 Chat Completions 地址、Key 和模型。各功能的开关在「功能」页的卡片上，点卡片上的滑杆图标打开该功能自己的设置；常用功能可以收藏或置顶。

### 从旧脚本迁移

「设置 → 数据 → 选择文件导入…」可以直接导入这些文件：

| 旧文件 | 导入内容 |
| --- | --- |
| 屏蔽脚本导出的配置 | 标题关键词 / 类别 / 标签及各自的正则规则、每个搜索词的过滤规则。和现有规则合并，不覆盖。 |
| 总结脚本「脚本配置」 | AI 接口（多套）、提示词、提问预设、DeArrow 设置与作用范围、通知、列表总结、Drive 凭据、「已总结」标记 |
| 总结脚本「总结内容」 | 每个话题的总结历史 |
| 总结脚本「全部数据」 | 以上配置，加上总结历史、问答历史、DeArrow 判断 / 改写状态 |

数据按话题合并。导入前会弹出确认框，说明识别到的文件类型。Google Drive 的文件夹布局与旧总结脚本一致，填入原来的凭据后可以继续使用云端数据。

## 功能

| 功能 | 默认 | 说明 |
| --- | --- | --- |
| 话题屏蔽 | 开 | 按标题关键词、类别、标签隐藏列表里的话题，三类都支持正则（`/pattern/flags`）。在话题行划词可直接添加规则；可查看某个话题被屏蔽的原因并取消屏蔽。关键词编辑器支持搜索、一次添加多个、按拼音（A–Z 分组，可跳转）或添加顺序排列，以及逗号分隔的批量编辑。页面右侧悬浮的「已屏蔽 N」按钮可以随时临时显示被屏蔽的话题，这时每行仍有屏蔽按钮。 |
| 搜索过滤 | 开 | 按搜索词分别保存「屏蔽词 / 必含词 / 正则」，过滤搜索结果，可一键显示被过滤的结果。全部搜索词的规则也可以在「设置 → 搜索过滤」的「搜索词规则」里查看和编辑。与原屏蔽脚本相同，搜索页右侧有两个悬浮按钮：上方的过滤计数（点击临时显示被过滤的结果，可选「图标 + 计数」或「圆形图标 + 角标」样式），下方的红色 ⊘（打开规则面板）。悬停结果时右上角出现屏蔽按钮（已过滤的结果可查看原因并删除规则），不改变结果布局。可选同时套用话题屏蔽规则。 |
| 话题 AI 总结 | 开 | 在话题页侧栏总结全部楼层，可附带站内图片；保留历史版本。支持多套提示词、Markdown / HTML 输出、自动总结、失败重试，linux.do 限流（429）时自动退避。侧栏宽度与原生侧边栏对齐（随拖动变化），外侧的展开 / 折叠手柄始终可见；快捷键 Alt + S。 |
| 列表 AI 总结 | 开 | 在话题列表每一行加「总结」「提问」按钮，在该行下方展开总结、历史和问答。依赖「话题 AI 总结」。 |
| 提问 / 追问 | 开 | 针对话题向 AI 提问，保存问答记录。有内置和自定义预设；输入框里按 `/` 选预设，Ctrl / ⌘ + Enter 发送。 |
| DeArrow 标题党改写 | 关 | 在作用范围内的列表页里自动用 AI 判断标题党，并根据首帖改写成具体、中立的标题；其他列表也显示 DeArrow 按钮和已改写的标题，可手动改写，不会自动消耗额度。悬停 ✦ 按钮可以临时看原标题。子选项「修正错别字」（默认开）在作用范围内找出标题里写错的字并改正显示，只改错字、不动措辞，改过的字带点状下划线。屏蔽规则始终按**原标题**判断。 |
| Google Drive 同步 | 关 | 把总结、问答和 DeArrow 状态同步到你自己的 Google Drive，在多台设备间共用。 |

另有几个核心模块：AI 接口（多套配置、测试连接）、通知（各类型的自动关闭时间、点击通知跳到对应话题）、设置面板（功能开关即时生效、数据导入导出、本地存储统计与清理）。

发布者头像调整、超宽显示与窄顶栏（默认开启，由停更的「LinuxDo自定义🛠️」脚本移植）：话题列表第一位发布者头像放大并加载清晰版本；页面铺满窗口宽度、顶栏变窄，两项可分别开关。

中英文混排优化、话题列表显示创建时间、禁用视频自动播放（默认开启，由停更的 linuxdo-scripts 移植）：帖子正文和标题里的中英文、数字之间自动加空格（pangu.js），编辑器里的「混排优化」按钮整理正在写的内容，代码和链接地址保持不变；话题列表显示创建时间，可替换浏览量（表头随之变为「创建时间」，点击按创建时间排序）或追加在活动时间后，按新旧着色；帖子里嵌入的 B 站、YouTube 播放器不再自动播放，点击加载的视频照常播放。

去除隐藏水印（默认开启）：页面上出现与账号关联的水印层（满屏半透明的用户名、平铺水印图、透明画布、混合模式的盲水印，包括放在封闭 shadow DOM 里的）时立刻用样式藏起来，截图里不会带上；不改动网页自己的元素，设置里可查看本页藏了什么、临时显示核对。烧进图片里的水印和浏览器指纹不在此列。

关键词搜索增强（默认开启，由「[LINUX DO] Keywords Search Enhanced」脚本移植）：常搜的关键词（各带一种排序）和常用链接存起来，点搜索框里的 🏷️ 一键搜索或打开；排序标签颜色可调，能导入 / 导出原脚本的文件。

问候语自定义（默认开启，由「[LinuxDo] 问候语自定义」脚本移植，对照 Void++ CustomGreeting）：首页欢迎横幅显示自定义问候语，多条按顺序或随机切换，时机可选进入首页、定时或点击标题；右键双击标题打开设置。

侧边栏宽度（默认开启，由「Sidebar ↔️ Enhancer」脚本移植）：拖动左侧边栏右边缘调整宽度并记住，双击恢复默认，默认只有边缘顶部 1/3 高度可拖动（可在设置中改为整条边缘）；只覆盖 Discourse 的 `--d-sidebar-width`，折叠侧边栏时正文正常铺满。首次启动沿用旧脚本保存的宽度；旧脚本仍在运行时会提示停用。

主题与快速 CSS（对照 Void++）：「主题」页可导入 Stylus 样式（`.user.css`，支持 `==UserStyle==` 元数据、`@var` 变量、预处理器 default / uso、`@-moz-document` 限定范围），也可导入 Stylus 备份 JSON（列出其中作用于 linux.do 的样式）、从网址安装（每天检查更新）或新建；带变量的样式可在卡片上调整变量，即时生效。「快速 CSS」页写的 CSS 输入即生效，排在所有主题之后。

从 Void++ 移植的七项（对照 [Void++](https://github.com/0-V-linuxdo/VoidPP/tree/dev) 同名思路）：

- 后台完成提醒（默认开启，对照 ResponseNotification / ChatStateFavicons）：AI 总结或提问完成、失败时播放提示音（可换成自定义音频地址），可选弹出浏览器系统通知，默认只在标签页处于后台时提醒；标签页图标在进行中显示蓝点，后台完成后显示绿点（失败红点），回到标签页即恢复。
- 话题导出（默认开启，对照 ExportChat）：话题底部「导出」按钮把全部楼层存为 Markdown / HTML / 纯文本 / JSON，含楼层号、作者、时间，可附上最新的 AI 总结。
- 楼层完整时间（默认开启，对照 MessageTimestamps）：每层楼的「3 小时」旁直接显示发帖时间（今天只显示时分），也可替换相对时间；悬停看到秒。
- 隐私打码（默认关闭，对照 StreamerMode）：模糊顶栏头像、未读数、用户菜单列表、侧栏私信分区，可选自己楼层的头像和用户名；悬停临时显示，脚本菜单「暂停 / 恢复隐私打码」。
- 提问输入历史（「提问 / 追问」的设置项，默认开启，对照 InputHistory）：提问框按 ↑ / ↓ 翻看问过的问题，Esc 回到正在输入的内容。
- 最近话题切换器（默认开启，对照 RecentTopics）：Ctrl + ` 弹出最近打开的话题卡片（标题、读到第几楼、总结开头）；按住 Ctrl 连按 ` 切换（Shift 反向），松开即打开并跳到上次读到的楼层；方向键、Enter、Esc 也可用。
- 自定义头像与名字（默认关闭，对照 CustomSidebarIdentity）：把自己的头像换成任意图片（填网址、粘贴或拖入、选择文件），在圆圈里拖动、滚轮缩放来裁剪；顶栏、用户菜单、楼层、列表、用户卡片里你的头像都会替换（可改成只换顶栏），楼层里的名字换成自定义显示名，顶栏头像大小可调。只在你的浏览器里显示，别人看到的不变。

## 为什么不再打架

旧版的两个脚本各自监听 DOM、各自改标题和隐藏行，并以 DOM 当前的样子作为状态。DeArrow 改写标题后，屏蔽脚本按新标题重新判断；它隐藏或恢复行之后，总结脚本又重新插入按钮。两边互相触发，造成标题漂移和行反复隐藏 / 显示等问题。

LD++ 里，话题列表由 `src/api/TopicList.ts` 一个模块负责：

1. **提取**：读每一行的 ID、原标题、类别、标签，原标题保存在数据模型里，之后不再从 DOM 读取。
2. **过滤**：所有过滤器（目前是话题屏蔽）只看原标题和元数据。
3. **标题呈现**：DeArrow 只提交「这个话题显示什么标题」，由管线统一写入 DOM。
4. **操作栏**：各插件注册带顺序的装饰器，按钮放进每行唯一的 `.ldpp-actions`，位置固定。
5. **面板行**：列表总结 / 问答面板由管线管理，行隐藏时面板一起隐藏。

管线只用一个 MutationObserver，并忽略自己写入的节点和文本。每一遍处理都是幂等的：结果不变时不写 DOM。验收时页面空闲 8 秒，LD++ 自身产生的 DOM 变更为 0。

## 开发

需要 [Bun](https://bun.sh) ≥ 1.1。

```bash
bun install
```

```bash
bun run build
```

| 命令 | 作用 |
| --- | --- |
| `bun run build` | 生成 `userscript/LDPP.user.js` 与 `LDPP.meta.js` |
| `bun run build:dev` | 生成带 `.dev` 插件的调试版 `dist/LDPP.dev.user.js` |
| `bun run watch` | 监听源码并重新构建 |
| `bun test` | 单元测试（happy-dom） |
| `bun run tsc` | 类型检查 |
| `bun run lint` | oxlint |

目录：

```
src/
  index.ts / LDPP.ts      入口与初始化顺序
  api/                    TopicList 管线、设置、插件管理、事件、导航、AI、Discourse 接口、数据仓库、通知、对话框
  components/             图标、表单控件、全局样式
  utils/                  DOM、CSS 注册、Markdown、HTML 净化、GM 封装、SettingsStore
  plugins/_core/          AI 接口、通知、设置面板（必需，不可关闭）
  plugins/<name>/         各功能插件，每个目录一个 definePlugin
test/                     单元测试
test/harness/           在真实 linux.do 页面上加载构建产物的验收工具（mock AI）
```

新插件放在 `src/plugins/<name>/index.ts`，构建时自动收集。插件不应直接操作话题行，而是用 `registerFilter` / `registerDecorator` / `registerProcessor` / `setTitleOverride` 接入管线。

### 在真实页面上验收

```bash
bun run test/harness/serve.ts
```

然后在浏览器打开 `http://127.0.0.1:8787/test/harness/loader.html?to=https://linux.do/latest`。加载器会把 GM 垫片和构建产物带到 linux.do，AI 请求由垫片中的 mock 接口（`https://mock.ldpp.test/v1/chat/completions`）应答，不需要真实 Key。

## 隐私

- 设置和数据保存在脚本管理器的存储里（`GM_setValue`）。
- 只有你配置的 AI 接口和（开启时）Google Drive 会收到数据。
- 导出备份时默认不含 API Key 和 Drive 凭据。
